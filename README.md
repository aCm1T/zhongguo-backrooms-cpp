# 华夏无尽回廊 · C++ 实时光线追踪版

原生 C++20 / SDL2 / OpenGL 3.3 游戏。画面不是传统三角形光栅化场景：全屏片元着色器为每个像素发射摄像机射线，通过 SDF 球面追踪求交，并继续发射阴影射线与反射射线。

## 完整界面流程

- 光追动态背景主页：继续漫游、新游戏、地域档案、设置、制作档案与退出确认
- 游戏内暂停菜单，可恢复、切换区域、调整设置或返回主页
- 中文地域档案，显示十个区域和九枚印记的收录状态，并支持直接投送
- 设置页：自动/低/中/高光追、全屏、垂直同步、鼠标灵敏度、HUD 和主音量
- 新游戏覆盖确认、退出保存确认以及九枚印记收集后的结算页
- Pango + Cairo 中文界面纹理，与光线追踪画面在 GPU 中进行透明合成

## 玩法与声音

- 各区域具有独立出生点和印记坐标；江南出生在河岸，四川避开中央茶桌
- 主要物件具备 CPU 近似碰撞：总站立柱、胡同木杆、江南水道、重庆阶梯、茶桌、陶俑、候车长椅和岭南盆栽
- 地下长安的陶俑中轴留有通道，江南石桥是跨越水道的有效路径
- 总站深处的门可以用 `E` 互动，并打开地域档案投送界面
- 武器系统：`1` 传送枪、`2` USP、`3` AK-47；滚轮切枪，`Q` 回到上一把，`R` 装填
- 传送枪：左键放置蓝门、右键放置橙门；走进任一门即可传送，并可透过门看见另一侧
- Dust II 上的部分掩体可被 USP / AK 打碎
- SDL2 程序化立体声环境音：荧光灯低频、江南/岭南雨声、重庆电流、东北风雪、茶馆泛音、区域化脚步，以及枪火 / 传送音效

进度和设置保存在系统用户数据目录的 `huaxia-backrooms/` 下；旧版工作目录存档会被自动读取迁移。

## 光线追踪特性

- 每像素主射线和 SDF 几何求交
- 最多 30 步软阴影射线，并随自适应画质动态调整
- 一次镜面反射射线，江南水面具有高反射率
- 传送门一次递归透视（蓝 / 橙成对时）
- 数值法表面法线、环境光遮蔽、距离雾
- ACES 风格色调映射、暗角、胶片扫描线
- 程序化雨、雪、荧光灯、灯笼和霓虹
- 第一人称枪械 / 传送枪视图模型

## 十个空间

`0` 无名总站；`1` 北京胡同；`2` 江南水院；`3` 重庆垂直迷城；`4` 四川茶馆；`5` 地下长安；`6` 敦煌洞窟；`7` 东北候车室；`8` 岭南骑楼；`9` 沙漠 Dust II（CS 压缩复刻：T Spawn / Mid / Long A / Short A / Cat / A Site / B Tunnels / B Site）。

区域建筑全部在 GPU 中实时生成。华夏区域含朱门与灯笼、白墙黛瓦和石桥、错层平台与霓虹、茶桌竹椅、陶俑券门、洞窟飘带、候车长椅与暖气片、骑楼立柱与满洲窗；Dust II 为开阔沙漠室外布局，不走走廊模板。

本作目前是「传送门式空间玩具 + CS 式枪械手感」的混合实验：漫游与乡音收集仍是主线，武器与传送门可在全部区域使用，Dust II 最适合当作射击 / 传送门沙盘。

## 编译运行

项目会链接系统现有的 SDL2 运行库，并在运行时加载 OpenGL 函数，不需要额外安装 SDL/OpenGL 开发头文件。

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DCMAKE_CXX_COMPILER=/usr/bin/g++
cmake --build build -j
./build/huaxia_backrooms
```

这里显式选择 `/usr/bin/g++`，是为了避开部分 Linux 环境中指向只读缓存目录的系统级 `ccache` 包装器。

也可以用 `./build/huaxia_backrooms --zone 2` 直接从指定区域启动，编号范围为 `0—9`。

## GPU 选择与兼容

默认使用 `--gpu auto --quality auto`：

1. 如果 NVIDIA 内核设备和 GLX 驱动均可用，启动前自动启用 PRIME Render Offload。
2. NVIDIA Offload 创建上下文失败时，自动恢复环境并使用系统 OpenGL 驱动重试。
3. 没有 NVIDIA 的设备直接使用系统提供的 AMD、Intel、Apple/Mesa 或软件 OpenGL。
4. 程序读取真实的 `GL_VENDOR` 和 `GL_RENDERER`：NVIDIA 从高画质启动，AMD/Intel 从中画质启动，软件渲染从低画质启动。
5. 自动档会根据实际 FPS 继续调整。低于 28 FPS 会降低射线、阴影和 AO 步数；持续高于 57 FPS 才会谨慎升级。

可手动覆盖：

```bash
# 强制尝试 NVIDIA PRIME Offload
./build/huaxia_backrooms --gpu nvidia

# 禁止独显覆盖，使用桌面当前 GPU
./build/huaxia_backrooms --gpu system

# 手动画质；可选 low、medium、high 或 auto
./build/huaxia_backrooms --quality high
```

所有档位仍然执行主射线和 SDF 求交。低画质只减少最大追踪步数、软阴影采样、AO 采样，并把二次反射限制在水面；不会退回传统二维或无光追渲染。

## 操作

- `WASD`：移动（默认跑动），`Shift`：静步，鼠标：环视
- `Space`：跳跃，`Ctrl` / `C`：按住下蹲
- `1` / `2` / `3`：传送枪 / USP / AK-47，滚轮切枪，`Q`：上一把武器，`R`：装填
- 传送枪：`LMB` 蓝门，`RMB` 橙门；走进传送门即可穿越
- USP / AK：`LMB` 开火（AK 可连发）；Dust II 掩体可被打碎
- `Tab` / `Shift+Tab`：下一个 / 上一个区域（也可在地域档案中投送）
- `E`：靠近区域深处的红色乡音印记后收集
- `M`：隐藏或显示 HUD，`Esc`：打开暂停菜单
- 菜单中使用鼠标或方向键移动，`Enter` 确认，`Esc` 返回

清空进度需要从主页选择“新的漫游”并确认，不再使用容易误触的快捷键。
